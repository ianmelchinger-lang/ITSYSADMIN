Write the definition: three answers

A scheduled job is work that a scheduler starts by itself from a stored definition, with nobody signed in. The definition stands in for you. It holds three answers:

  • The trigger says when the job starts.
  • The action says which command the scheduler starts.
  • The run-as account says as whom the command runs.

Here is a chore that someone does by hand every night.

Sort the eight pieces of the story. Put each piece in the slot it answers, or mark it as none of the three. Nothing here is scored.

The definition card the scheduler holds

The scheduler consults this card and nothing else. Whatever the card holds, the job has. Whatever it leaves out, the job lacks, because nobody is there to supply it. Try leaving a slot out.

At the keyboard, “I sign in as myself” answered “as whom” simply by being true. In a definition, that answer has to be written down as an account.

Platforms write the same answers in different forms. Cron, the Linux scheduler, places five ordered time-and-date fields before the command. Task Scheduler, the Windows scheduler, attaches a trigger to a named task. You translate the answers from one platform to the other, and you never copy them.
