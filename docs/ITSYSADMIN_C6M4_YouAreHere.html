The morning after an unattended run

A scheduler is the part of an operating system that starts work by itself at set times. Last night a scheduler started a report job at 02:00 on a Windows server, and nobody was signed in. It is now 07:55. Finance asks one question before its 08:00 meeting: was last night's report produced?

Four items sit on your desk. For each one, decide whether you would rely on it to answer “yes, it was produced.” Commit to your answers first. Then see what each item speaks to. Nothing here is scored.

The scheduler’s record

In plain words: started at 02:00, ended normally.

It speaks to: whether the job started, and how it ended.

A script that meets an error it does not treat as fatal carries on to its last line and ends in the ordinary way. An ordinary ending therefore cannot tell work done from work skipped.

Yesterday’s hand test

You ran the script yourself, signed in. It worked.

It speaks to: one run, by one identity, in one session.

The test ran as you, with your permissions and settings. The scheduler starts the script from a stored definition, under whatever account that definition names. A test proves a script for one identity and says nothing about any other.

The quiet inbox

Nobody has reported a problem.

It speaks to: whether anyone has looked and complained.

A complaint needs a witness. Nobody was signed in to see the run, so silence looks the same whether the job did its work or not.

The task’s listing

The task is registered. Its trigger is set to 02:00, and it names the account it runs as.

It speaks to: how the job is set up to run.

A listing shows the definition the scheduler holds: when, what, and as whom. It cannot show what the job did at 02:00.

The item that is not on the desk

What would settle the question is a line the job wrote itself, after everyone signed off, with a date and a statement of what it did. It is not here, because nothing in this job was built to write it.

The capability this module builds is making an unattended job leave its own proof, before its first night, so that the morning has something to read.
