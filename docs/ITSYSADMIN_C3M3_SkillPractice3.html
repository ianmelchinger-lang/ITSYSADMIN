Both Ends of the Session

A management session connects two configured machines: the one doing the managing and the one being managed. When you sign in, a credential leaves your workstation, crosses the network, and arrives at the server. Each end has its own setting for how it sends or accepts that credential, and the session runs only on terms both ends allow.

Hardening guidance for Windows Server requires the management transport to be configured so that credentials do not cross it in plain text. It applies that rule at both ends of the session.

Plain text matters because anyone who can watch the network traffic can read a credential sent that way.
