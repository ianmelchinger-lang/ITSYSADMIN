Hands-on exercise · about 5 minutes · nothing here is graded

Walk the script a second time

A script that a person or a scheduler starts again begins each run from whatever the last run left behind. A step that makes a change may complain, repeat its work, or fail the second time. A step that first asks for the condition it wants does nothing when that condition already holds. Here you walk a script through its second run and find the lines that go wrong.

Key ideas

Idempotent
Describes a step, or a whole script, that leaves the same result whether it runs once or many times.
Asks for a condition
A step that states what it wants, such as “the folder exists,” and does nothing when that is already true.
Makes a change
A step that creates, adds, or moves something every time it runs.

Practice: the second run

The first run has already finished, and every line’s work is done. Take each line on its own and ask what it does when its work is already done.

Play: change the wording

Nothing here is marked right or wrong. For each job, choose how the line is worded, then read what the second run does.
