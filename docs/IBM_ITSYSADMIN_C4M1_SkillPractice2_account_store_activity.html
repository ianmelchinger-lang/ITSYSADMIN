Which of These Hold the Account?

A contractor works across two of Sample Enterprise Manufacturing's systems: a build server and a project-tracking server. Several other systems and lists also mention the contractor somewhere. Only some of these actually hold an independent account record — a place where a removal would need to happen on its own.

Sort each item: does it hold its own independent account record for the contractor, or not?

One assumption, moved

Suppose instead the build server and the project-tracking server no longer keep their own local accounts. Suppose both are joined to a single directory service, and both trust it for sign-in.

Under that setup, does clearing the contractor's one account in the directory end their access to both servers?
