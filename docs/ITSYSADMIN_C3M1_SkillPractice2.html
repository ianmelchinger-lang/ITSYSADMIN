Requested, present, or running?

A record that says "done" and a machine that is done are not the same thing, and the gap between them has a shape worth knowing.

Three separate facts sit behind "the capability is there," each written in a different place. What was requested lives in the tool you installed with. What is present lives on the host itself — you learn it by asking the host which roles it provides. Whether it is running can wait on a restart, a third moment with its own record. Because they are recorded separately, they can disagree.

Here is the claim on the ticket, and the evidence in front of you. Trace each piece to the fact it actually speaks to, then say how strongly the claim can be written.

The claim on the ticket

File and Storage Services is present and running on this host. The drive is ready.

So how strongly can the claim — present and running — be written right now?

Now one record changes

Nothing else moves. You run the query against the host again — and this time the reply is different:

The host now lists File and Storage Services among the roles it provides.

The restart is still pending. How strongly can the claim be written now?
