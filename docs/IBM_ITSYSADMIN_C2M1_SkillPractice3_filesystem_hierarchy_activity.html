Checked, or Just Familiar

Eight moments from admins settling where a file belongs on the storefront host. Some of them checked something written down. Some of them didn't — even when the reasoning sounds confident. Sort by which is which.

The layout wasn't invented by this host or this vendor, and it's written down in a document you can open yourself. Sort each moment into checked against documentation or guessed from resemblance or habit — regardless of whether you think the admin landed in the right place.

Now move one assumption

Same admin, same destination directory, same startup scripts. Only one thing changes: whether anything got checked before the file landed there.

The file ends up in the exact same directory either way. What moves is only whether that placement is something you could defend to a colleague by pointing at a document, or something you'd have to defend by saying it felt right.

A directory's purpose is something you look up, not something you land on by how confident the reasoning sounds. Wherever documentation was actually opened, the placement can be checked by anyone. Wherever it wasn't, the placement only holds up as long as nobody asks why.
