Assemble the path from problem to proof

A script is ready to run unwatched only when you can state the problem it solves, name the moves that make it fit, and point to the evidence that the moves worked. Here you assemble all three on one board. Pick the problem statement, put the moves in an order that holds up, and choose the evidence that shows the script is fit.

Key ideas

Fail-fast
A way of running a script in which the first failed command ends the run, so no later step acts on what the failure left behind.
Idempotent
Describes a step, or a whole script, that leaves the same result whether it runs once or many times.
Exit status
The number a command returns when it ends. Zero means success, and any other number means failure.
