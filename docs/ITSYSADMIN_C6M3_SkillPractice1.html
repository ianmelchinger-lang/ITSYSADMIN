Read both reports from each line

A command reports twice. What it prints is for the person watching. The number it returns is for the shell, and for any program or reader that runs the script later. When a script runs without you, only the number can be acted on. Here you read each line’s number, then work out the one number the whole script reports.

Key ideas

Exit status
The number a command returns when it ends, separate from anything it prints. Zero means the command succeeded. Any other number means it failed.
Shell
The program that reads a script and runs its lines, one after another.
