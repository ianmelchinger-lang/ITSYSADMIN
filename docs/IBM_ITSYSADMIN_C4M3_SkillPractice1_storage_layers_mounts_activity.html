Skill Practice — Storage Layers and Mounts

One path. Two different things could be sitting behind it.

A filesystem sits on vol-archive-01, and one file — before-mount.txt — already sits in the /data/archive directory beneath it. That file is the panel's starting condition, not a fault you are being asked to find. Toggle the mount and watch which files appear at the path. Mounting hides before-mount.txt; unmounting brings it back — nothing here is deleted, and nothing refuses you. On a real machine one thing will refuse you: you cannot shrink a mounted filesystem, and that is a safety control working, not an error.
