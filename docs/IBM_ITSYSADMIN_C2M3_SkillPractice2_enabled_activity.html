Three Strengths of Off

A unit is enabled when it's been placed in the boot path, so it starts on its own at the next boot. Turning something off isn't one action — it's a choice among three, and the choice depends on what you actually need to hold true.

Stopping a unit affects only the current run. If it's enabled, it comes back at the next boot regardless.

Disabling a unit removes it from the boot path. It won't start on its own — but someone can still start it by hand.

Masking a unit blocks it from starting at all, by anyone, until the mask is removed.

Read what's actually required, then choose the matching action.
