Name the line that must never run

Fail-fast means the first failed command ends the run, so no later step acts on what the failure left behind. The stop is a setting an author switches on, and then proves with a forced failure: break one step on purpose and watch the lines after it. Here you decide which later lines must never run, then force the failure and read the result.

Key ideas

Fail-fast
A way of running a script in which the first failed command ends the run. In Bash it is a setting the author turns on, named errexit. The shell leaves it off until asked.
Forced failure
A step you break on purpose, so you can see whether a protection works.

Practice: break line 2

A five-line script changes the web server’s settings. Its stop is on. Each card says what the line does and what it relies on.
