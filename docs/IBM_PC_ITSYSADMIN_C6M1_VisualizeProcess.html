Put the Monitoring Steps in Order

Everything in monitoring waits on something earlier. A reading needs a normal to be judged against, and a normal needs a record to be drawn from. Assemble the whole path, from the problem to the signal that it worked, and check that each step has what it needs before it.

Your path starts with the problem, ends with the signal that the fix worked, and holds the moves in between.

Some cards do not belong on this path. Set those aside.

More than one order can be right. The check flags only a step that comes before something it depends on.
