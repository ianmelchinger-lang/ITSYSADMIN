Will It Survive the Reboot?

A colleague on the retail side sends you a screenshot from this morning's incident, along with a note.

Message from retail ops It's up and running — so it's configured correctly. We're good heading into tonight's reboot.
Before you see anything else: will this service still be running after tonight's reboot?

Someone started this unit by hand while working the incident this morning. It is genuinely running right now — the first screenshot wasn't wrong. But it was never placed in the boot path. Tonight's reboot will not bring it back. The host will come up looking exactly like it did before anyone touched it.

The first screenshot could only ever answer one question: what's true this minute. Whether something returns after a reboot is a separate fact, kept in a separate place on the host. No amount of staring harder at the first reading would have produced it — favorable or not.

Running right now and set to return after a reboot are two different facts about a host, recorded in two different places. Telling them apart, and checking each one on its own evidence, is the skill this module builds.
