You look after the storefront of a mid-market retailer during its seasonal peak. Staff at a regional office cannot open the storefront's order screen. The help desk passes you their ticket.

The ticket says

"It will not connect."

That is all it says. Before anyone asks what is wrong, you already have three results. You ran all three from your own desk.

  2. A ping to the storefront host gets no reply.
  3. You look the name up with two tools. One returns an address. The other cannot find the name.

Every result is true. Each one describes the path it crossed, from the desk it ran on. The users' request has a path of its own, and four of its five links have not met a single test. The ticket would read the same wherever along that path the break sits.

The capability this module builds is locating the one link where a request stops, and proving it with a test, before anything is changed.

It has to be in place before a repair can be chosen, confirmed, or written down for the next person.
