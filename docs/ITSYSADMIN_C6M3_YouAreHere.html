What a quiet finish tells you

Some routine work runs without anyone watching: copying files, clearing space, closing out the week. When someone later asks whether a job did its work, you need an answer you can defend. Here you take that seat. Commit to a reading first, then compare it with what the evidence can support.

The situation

A script named archive-logs.sh runs once a week on the storefront server, cld-lnx-01. A script is a file of commands that the computer runs one after another. This one makes today’s folder in /data/archive, copies the week’s application logs into it from /var/log/storefront, and then deletes the originals from the server.

You started Tuesday’s run and stepped away. When you look up, here is what you can see:

  • The prompt is back, so the job has finished.
  • The server has more free disk space than before.
  • The archive folder lists files dated today.
  • The script file is still in the scripts folder.

On Thursday, the owner of the storefront application will ask whether Tuesday’s logs can be retrieved.

Your reading

Answer both questions, then lock in your reading. You cannot change it afterward, so you can compare it honestly with what follows.

What would you tell the application owner on Thursday?
Which one of these would you accept as proof that Tuesday’s run did all its work?
