Should this port be opened?

A ticket asks you to change a firewall rule. It sounds like a decision already made. Before you change anything, check whether the rule is what actually stands between this client and the service.

Port.
A number that directs an arriving request to a service on a host. The service’s configuration sets it. The client must request the same one.
Firewall zone.
A named set of rules applied to a network interface. Only the active zone on that interface decides what gets through. Traffic on a port it does not permit is dropped.
