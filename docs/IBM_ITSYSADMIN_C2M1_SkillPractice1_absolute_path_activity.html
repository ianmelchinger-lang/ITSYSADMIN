Will It Land Them in the Same Place

A colleague asks where a file lives on the storefront host. Some ways of answering will put them exactly where you meant, no matter who they are or where they're standing when they look. Others only work if they happen to be standing where you were.

Sort each answer below into will land them in the same place or depends on where they're standing. Nothing here needs a running host — read each string for what it commits to.

Now move the assumption: where is your colleague standing?

Same eight answers. This time, watch what happens to the ones that "depend on where they're standing" when the standing point actually changes — and what happens to the ones that don't.

The four in green never moved — a root-anchored string doesn't care who's reading it or where they started. The four in brick moved with the context, and one of them (../finance-wip/…) didn't just move — it now points into a completely different directory that happens to share a name.

An absolute path is the one form of "where is it" that survives being handed to someone else. Everything else is a direction, not a location — accurate only from where you happened to be standing when you gave it.
