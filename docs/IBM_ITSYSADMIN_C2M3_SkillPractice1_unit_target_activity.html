Sort the Host

Everything a host is doing or set up to do is one of a few typed things. Read each line below and say what it actually is.

Unit — a named thing systemd manages, of a stated type: a service, a socket, a timer, a mount, or a target. Each one is backed by its own file.

Target — a named group of units standing for a state the host can be in. It's not a single running thing; it's what several units add up to.

For each line, choose what it is.

    A least-functionality review is nothing more mysterious than this: naming what each unit actually is, sorted by type. Once you can do that, "run only what the job needs" stops being a feeling and becomes a list you can check.
