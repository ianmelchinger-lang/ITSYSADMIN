Write the line you want to find tomorrow

When someone asks whether a job finished on a given day, and how it ended, you can answer only from what the run itself recorded. A script file shows what would be done. A dated line the run writes shows what was done. Start from the one line you want to find the morning after, then test it on a reader who has never seen the script.

Key ideas

Run record
A dated line that a script writes itself, saying what the run did and how it ended.
Exit status
The number a command or script returns when it ends. Zero means success. Any other number means failure.
