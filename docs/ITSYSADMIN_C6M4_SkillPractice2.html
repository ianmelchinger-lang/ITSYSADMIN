What the hand test borrowed

You tested a script by hand, and it worked. A scheduled job does not start from your session. The scheduler starts it from a stored definition, with nobody signed in, and the definition names the account the job runs as. Whatever your session supplied, that account may lack.

One term first. The execution policy is a safety setting that some shells carry. It can refuse to run script files, and it applies by scope, so a setting made for one user covers that user.

You will do two things. First you find what the test borrowed. Then you check each borrowed condition against a sheet for the account the job will use. Nothing here is scored.
