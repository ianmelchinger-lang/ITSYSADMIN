Attach it where it reaches

A directory keeps its entries in a tree, not a list. Every entry has a position, and a setting can be attached to a position instead of to each entry one by one. Here, the positions are two containers, one for each warehouse, holding the clerks' accounts.

The requirement. The south warehouse's sign-in settings must apply to every south clerk account, and to no north clerk account.

Select any container or any account to attach the settings there. Select it again to remove them. The accounts the settings reach turn green.
