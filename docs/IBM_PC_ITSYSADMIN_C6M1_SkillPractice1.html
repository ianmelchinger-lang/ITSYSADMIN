Check What the Collector Recorded

A server can tell you about its past only through samples a collector took and kept. Three settings decide which questions that record can ever answer, so check them before you promise anyone an answer.

The collector on the storefront server

Suppose a collector, a small program that measures the server and writes each measurement down, has been running on cld-lnx-01 with these settings. The settings are made up for this exercise. They are not any product's defaults.

  • Collection began
  • Sampling interval
  • Files kept for

The sampling interval is the fixed gap between one measurement and the next. The band is a sketch, not to scale.

Check each question in this order

  1. Did the moment come before collection began? Then the record never held it.
  2. Is the moment older than the files are kept? Then its samples have expired.
  3. Did the event last less than one sampling interval? Then it was averaged into its sample or fell between two.
  4. If none of these applies, the record can answer it.

Move one setting and watch the answers move
