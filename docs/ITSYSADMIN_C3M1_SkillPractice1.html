Platform, or capability?

"The server is up" and "the server does this job" sound like one claim. They are two, and keeping them apart is where this starts.

A role is a named capability you add to a machine so it does a particular job for particular people. Underneath it sits the platform: what the operating system gives you the moment it is installed — a machine you can reach and administer, which does no job for anyone until a capability is added.

Here are things that might be true of one server. Sort each into what the platform gives you and what someone added as a capability.
