Trace the Files Before Deletion

Decide what a step applies to before you trust what it does.

A retailer's back office keeps a report-export folder on its Windows server. Someone has written a three-step cleanup for it. Each step hands the next one a set of objects. Here, each object is a file, and each file carries named properties: a name, an age in days, and a size in MB.

Before anyone runs the cleanup, work out which files step 3 will delete.

The cleanup as written

  1. List every file in the report-export folder.
  2. Keep only the files older than 30 days.
  3. Delete each file it receives.

Someone edits step 2

Step 2 now selects by a different property. Step 3 stays exactly as it was.

  1. List every file in the report-export folder.
  2. Keep only the files larger than 100 MB.Edited
  3. Delete each file it receives.Not edited
