Troubleshooting

Move the break, and watch which tests still pass

A connection from the storefront server cld-lnx-01 to file sharing on hq-win-01, by name, on TCP 445, depends on four links: this server's own address, the way across the shared network to hq-win-01, file sharing answering on port 445, and the name hq-win-01, which this server looks up in its own hosts file. The two servers share one network with no gateway between them, so there is no gateway link. You choose where the break is, and nothing is hidden. Five tests each cross a different set of links, and the last is the original check, which needs all four. Every test that crosses the broken link will fail, and every test that does not will pass, so the break is the one link every failing test crosses and no passing test does. Test 4 reads a file on this server and crosses only the name, so it can pass while earlier tests fail. The report will read the same wherever you put the break. In the troubleshooting records, the break is at the name. This panel is a model: it works each result out from the break you chose and probes no real network. Nothing here is scored.
