What does this evidence prove?

Monitoring says the label host is up. A north warehouse user still cannot load the pick-ticket page. Before you tell anyone the server is fine, sort out what each piece of evidence actually proves. Some claims will not be proved by anything here yet. Saying so is a correct answer.

Host.
A computer or virtual machine with an operating system.
Listening service.
A program on a host that waits for requests on a numbered port and responds to them. One host can run several, and each can fail on its own.
Address and port.
The address points a request toward a host. The port tells the host which service should receive it.
